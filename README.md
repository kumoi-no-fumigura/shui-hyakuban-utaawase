## 作品について

源氏物語の歌を左に、夜の寝覚・御津の浜松・とりかへばやなどの物語の歌を右に番えた百番の物語歌合。『物語二百番歌合』の後半にあたる。判詞はない。

## 底本

- [群書類従 第拾壹輯](https://dl.ndl.go.jp/pid/1879538)（塙保己一 編・経済雑誌社・1899年・p145-155）

国立国会図書館デジタルコレクションの「インターネット公開（保護期間満了）」の資料です。

## 本文の作り方

国立国会図書館の全文テキスト（OCR）から作品の範囲を切り出し、原本のページごとに段落に分け、ページの先頭や末尾にある書名（柱）を除きました。それ以外は手を加えていません。旧字の誤認識・ルビ・割注などがそのまま混じっています。

## 誤りを見つけたら


- **Issue で知らせる**：[「本文の誤り」の Issue を作る](https://github.com/kumoi-no-fumigura/shui-hyakuban-utaawase/issues/new?template=teisei.yml)。段落ID・いまの本文・直した本文・根拠を書いてください。

受け取った修正は、原本の画像と照らして確かめてから取り込みます。
